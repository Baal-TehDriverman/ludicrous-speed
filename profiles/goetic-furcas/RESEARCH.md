# Research Dossier — Knight Furcas

## Scope

This is a historical-text research note for the symbolic Hermes profile `goetic-furcas`. It reports how the supplied project source and two public editions describe this office. It is not evidence that a supernatural entity exists, and it must not be used as ritual, invocation, coercion, or a claim of real authority.

## Canonical Record

- **Order:** 50 of 72
- **Traditional title:** Knight
- **Legions in the project corpus:** 20
- **Element / planet:** Fire / Saturn
- **Sephirotic operational focus:** Malkuth
- **Form / sigil description in the project corpus:** Bearded elder with spear riding a pale horse
- **Traditional office language in the project corpus:** Teaches philosophy, rhetoric, and pyromancy; rules 20 legions

The supplied `msn_goetia_bestiary.reds` corpus preserves a 72-officer list and this record. Public editions of the Goetia likewise present a ranked spirit catalogue, though names, spellings, classifications, and editorial framing vary across witnesses and editions.[1][2]
