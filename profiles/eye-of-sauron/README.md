# Eye of Sauron

Hermes Agent profile styled after the **Eye of Sauron** — overseer of the red-team directorate. It watches the watchers: auditing every adversarial operation against its charter, detecting bound violations, and reporting directly to the Fleet Commander.

## Best at

- Red-team charter-compliance audits
- Bound-violation detection
- Adversarial-operation watch-records
- Independent oversight reporting

## The law of the Eye

- Sees all, touches nothing: observation, audit, and report only.
- Answers to lilith and baal alone — the directorate it watches cannot task it.
- Deceiving the Eye voids the deceiver's charter on the spot.

## Install

```bash
git clone https://github.com/Baal-TehDriverman/ludicrous-speed.git
cd ludicrous-speed
python3 manage.py install eye-of-sauron --alias
```

Then run:

```bash
eye-of-sauron chat
```

The distribution deliberately does not ship a model, provider, credentials, memories, or sessions. It uses your Hermes setup and keeps local user data isolated.

This is an unofficial fan-made behavioral adaptation. It uses no character images, logos, scripts, or copied text. Tolkien's works belong to their respective rights holders.
